# Sophis Brutos

Painel administrativo em Next.js para monitorar dashboard e configuracoes de pixels.

## O que este projeto e
A estrutura aponta para um produto enxuto da familia Sophia, com homepage publica, login e um dashboard administrativo focado em operacao e pixels. Em relacao ao `sophia-teste`, este repositorio parece ainda mais concentrado em fluxo basico de admin.

## Modulos principais
- `app/page.tsx`: pagina publica
- `app/admin/login`: acesso
- `app/admin/(dashboard)/dashboard`: visao principal
- `app/admin/(dashboard)/pixels`: configuracao e acompanhamento de pixels

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- React Hook Form

## Como rodar
```bash
npm install
npm run dev
```

## Comandos uteis
```bash
npm run build
npm run start
npm run lint
```

## Objetivo
Manter uma base simples para administracao e rastreamento dentro da linha Sophia.
