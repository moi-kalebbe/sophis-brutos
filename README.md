# Sophia Brutos

Landing page em Next.js com tracking, admin e foco em conversao comercial.

## O que este projeto e
Sophia Brutos e uma aplicacao em Next.js que combina landing page, tracking de origem de trafego e painel administrativo para gerenciar scripts e analytics. A home concentra secoes comerciais como hero, beneficios, produtos, prova social e CTA final.

## Stack
- Next.js 14
- React
- Tailwind CSS
- Supabase
- Recharts

## Funcionalidades
- landing page responsiva
- tracking de WhatsApp e UTMs
- painel admin em `/admin`
- ativacao e desativacao de pixels
- dashboard de analytics

## Como rodar
```bash
npm install
npm run dev
```

## Estrutura
- `app`: rotas e paginas
- `components/landing`: blocos da landing page
- `lib`: clientes e utilitarios
- `supabase`: auth e banco

## Objetivo
Oferecer uma experiencia comercial com tracking e operacao administravel sem alterar codigo a cada ajuste.
